# Дневной ориентир Codex

В карточке личного расхода показан ориентир в процентах полного недельного
лимита, не в токенах. Источник — существующий ответ Codex о лимитах; новые
аккаунты и разрешения не нужны.

Расчёт: `(100 − использовано %) × 0,9 / max(1, секунд до сброса / 86400)`.
Результат округляется вниз до десятых. Запас составляет 10% текущего остатка.
Если до сброса меньше суток, ориентир ограничен остатком с запасом.
Пример: осталось 60% и 3 суток — 18% полного недельного лимита в сутки.

Это обновляемый темп на следующие сутки, не накопительный личный счётчик
«сколько ещё можно сегодня». Дата сброса показана рядом. Отдельно выводится
текущий остаток 5-часового окна. Его исчерпание может заблокировать работу
раньше недельного; рекомендация не гарантирует бесперебойный доступ.
Фиксированного коэффициента перевода расхода токенов в лимит нет.

Ориентир отсутствует при статусе провайдера, отличном от ok, неизвестном
недельном окне/дате сброса, прошедшем сбросе или некорректных числах.
Тесты покрывают резерв, окно короче суток, исчерпанный лимит, пропущенные,
отрицательные и нечисловые значения. Цифры температуры и расхода сохранены
чёрными; цветовые состояния остаются на кольцах.

## Сбросы в запасе

Выделенная строка показывает `rate_limit_reset_credits.available_count` из
того же ответа usage. Это не платный баланс credits и не количество будущих
автоматических обновлений окна. Ноль отображается явно, отсутствующие или
устаревшие данные — «нет данных». Счётчик намеренно не сохраняется в старом
кэше: после запуска без связи неизвестность не подменяется нулём.

Сбросы показаны отдельно от дневного ориентира и не умножают его автоматически.
Приложение не расходует сбросы и не содержит кнопки их применения.

## Несколько пользователей

В настройках внешнего вида → «Системные показатели» можно выбрать от 1 до 4
пользователей общего лимита и вес своей доли от 1× до 4×. По умолчанию — трое,
своя доля 2×. Каждый из остальных имеет вес 1: это даёт 50% дневного ориентира
владельцу и по 25% двум остальным. Для четырёх с тем же весом — 40% и по 20%.
При одном пользователе весь ориентир принадлежит ему, настройка веса отключена.

Личная доля = `вес / (вес + число пользователей − 1)`. Она применяется к общему
ориентиру уже после резерва 10%. Карточка показывает свой бюджет на сутки,
бюджет каждого из остальных и общий бюджет. Это план распределения, а не
измерение или принудительное ограничение расхода отдельных людей; график
токенов остаётся общим для аккаунта.

Три столбика значка анимируются только при раскрытой панели, с ограниченной
частотой обновления. При системном Reduce Motion анимация отключена. Движение
декоративное: оно не означает, что агент сейчас работает или расходует токены.
