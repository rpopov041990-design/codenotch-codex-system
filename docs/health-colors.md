# Цвет температуры и памяти

## Температура

Число в кружке — среднее доступных температурных зон CPU/GPU. Цвет — отдельное
системное тепловое состояние `ProcessInfo.thermalState`:

| Состояние ОС | Цвет |
| --- | --- |
| nominal | Зелёный |
| fair | Жёлтый |
| serious | Оранжевый |
| critical | Красный |
| Неизвестно | Серый |

Не используем неподтверждённые «100/105/110 °C — предел M5». В проверенной
публичной спецификации M5 предельная температура кристалла не указана.
Диапазон 10–35 °C относится к условиям эксплуатации компьютера, не к CPU.
Среднее зон также не равно температуре самого горячего участка.
Нормальное состояние ОС не является гарантией отсутствия аппаратной неисправности.

## ОЗУ

Длина дуги и число по-прежнему показывают занятую память. Цвет отражает системное
давление памяти: normal — зелёный, warning — жёлтый, critical — красный,
нет данных — серый. Поэтому 85% занятости может оставаться зелёным.

Read-only `kern.memorystatus_vm_pressure_level` экспортирует dispatch flags
1/2/4. Не путать с внутренним перечислением ядра 0/1/2/3: sysctl преобразует его.
При ошибке чтения нет подмены на normal. Это индикатор состояния ядра, не копия
всего исторического графика Activity Monitor.

Тесты проверяют все четыре тепловых состояния, три флага давления памяти и
неизвестные значения. Физический перегрев и нехватка памяти искусственно не создаются.
