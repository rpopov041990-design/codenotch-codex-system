# Codenotch Windows · TEST / 0.1 preview

Отдельная экспериментальная реализация для Windows 10/11 x64 на C# / .NET 8 / Windows Forms. Swift-версия macOS не изменяется. Общий принцип сохранён: компактная правая панель, круговые показатели и раскрытие при наведении. Это не точная копия анимации и не полный паритет функций Mac.

## Возможности и честные ограничения

| Показатель | Windows preview |
|---|---|
| RAM | Занятая физическая память через GlobalMemoryStatusEx; метод отличается от macOS |
| CPU | Разница GetSystemTimes между замерами; первый замер без процента; >64 CPU ограничено группой процесса |
| Диск | Занято/свободно на томе профиля Windows, не сумма всех дисков |
| Батарея | Процент, зарядка, питание от сети; без батареи кружок скрывается |
| Износ АКБ / температура | Недоступны; показан прочерк, не выдуманный ноль |
| Codex | Только снимок rate_limits из локального rollout; дата и устаревание через 5 минут |
| История токенов / серии / аккаунты | В этой версии не перенесены |

На круге Codex **использованный** процент дополнительного окна, если оно есть, иначе основного. В подсказке длительности, оба окна и известные сроки сброса. Отсутствие снимка не означает свободный лимит. Истёкший снимок не превращается автоматически в ноль после сброса.

## Запуск

Для сборки нужен [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0). В PowerShell из корня репозитория:

```powershell
dotnet run --project windows/Codenotch.Tests -c Release
dotnet publish windows/Codenotch.Windows -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -o artifacts/windows-x64
.\artifacts\windows-x64\Codenotch.Windows.exe
```

Сборка self-contained: для полученного приложения отдельно устанавливать .NET не нужно. Артефакт `codenotch-windows-x64-TEST` создаётся успешным workflow **Windows preview** во вкладке Actions. Это ZIP с файлами приложения, не установщик. Распакуйте полностью. Сборка не подписана издательским сертификатом; не отключайте SmartScreen/антивирус ради её запуска. Корпоративные правила могут запрещать запуск — обратитесь к администратору.

Наведите курсор на правый край основной рабочей области. Подробности доступны при наведении на строку. Правый клик: закрепление панели, скрытие/показ и выход. Двойной клик по значку в трее возвращает панель. Esc сворачивает. Автозапуска, админ-прав и установки драйверов нет. Поддержка дополнительных мониторов и визуальная проверка на разных DPI требуют обратной связи.

## Приватность и источник Codex

Приложение не делает сетевых запросов, не открывает `auth.json`, не читает хранилище учётных данных и не подключает Claude/Cursor/других провайдеров. Не сохраняет показатели и содержимое журналов.

Используется `CODEX_HOME`, если он задан, иначе `%USERPROFILE%\.codex`. Просматриваются только недавние датированные каталоги `sessions/YYYY/MM/DD`, не более 20 журналов `rollout-*.jsonl` и ограниченные хвосты. Из прочитанных JSON-строк используются только timestamp и rate_limits событий token_count; содержимое чатов не показывается и не записывается. Это всё же чтение части журнала — запускайте только в своём профиле. Формат внутренних журналов может измениться; при несовместимости будет «нет снимка».

WSL-профиль и другой компьютер автоматически не ищутся. Доступную папку своего профиля можно явно передать через `CODEX_HOME` перед запуском. Нельзя копировать чужие токены для появления лимитов.

## Проверка и обратная связь

CI проверяет парсер на синтетических данных, read-only чтение, сборку и короткий запуск WinForms/системных датчиков. **Это не ручная проверка интерфейса и не испытание на физическом ноутбуке.** Проверьте зарядку, отсутствие батареи, сон/пробуждение, DPI 100/150/200%, появление свежего снимка Codex и скрытие панели.

В Issue укажите Windows build, архитектуру, масштаб экрана, ожидаемое/фактическое поведение. Не прикладывайте rollout, auth.json, токены или персональные скриншоты.
